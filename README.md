# Fault-tolerant control of robot manipulators: data, code and supplementary material

Data, code and supplementary material of the systematic review *Fault-Tolerant Control of Robot Manipulators: A Systematic
Review Linking Fault Models to Accommodation Strategies* (Review, MDPI *Sensors*, submitted). The manuscript itself is not
distributed here.

**Author:** Claudio Urrea, Department of Electrical Engineering, Faculty of Engineering, University of Santiago of Chile
(Las Sophoras 165, Estación Central, Santiago 9170020, Chile). ORCID: https://orcid.org/0000-0001-7197-8928.

**Registered protocol:** OSF Registries, https://doi.org/10.17605/OSF.IO/ECQA7 (version 1.11, last amendment of 25 November 2026).
**Repository:** https://github.com/ClaudioUrrea/ftc-manipulators-review. **Archive (Figshare):** https://doi.org/10.6084/m9.figshare.35106610.

## At a glance

- Protocol registered at OSF Registries before the blind validation coding and the synthesis; PRISMA 2020 and PRISMA-S
  checklists included (S7, S8).
- 2280 unique records from Web of Science and Scopus; 1042 primary studies in the coded mapping set; 105 studies analyzed
  at full text.
- Every fault model written in one normal form (84 of the 105 full-text studies map fully).
- Hardware evidence counted by fault class: 13 of 28 fault-by-accommodation cells.
- FAME-FI, a fault-injection reporting checklist for FTC experiments.
- Every number, table and figure of the article is regenerated by `run_all.py`.

## Contents

| Folder | Content |
|---|---|
| `data/` | Derived data: coded mapping set (S6), per-study extraction sheet of the full-text studies (S5; 105 eligible) and its dictionary, PRISMA counts (S3), search strings (S2), full-text exclusions (S4), agreement and recall counts |
| `results/` | Every count, proportion, interval and test of the analysis (CSV and JSON) |
| `figures/` | Figures of the analysis and the PRISMA 2020 flow diagram (PDF, PNG) |
| `supplementary/` | Supplementary material S1 to S13 (see `supplementary/INDEX.md`) |
| `code/` | Analysis and figure scripts; `code/archive/` holds the search and extraction scripts of the earlier stages |

Raw exports of Web of Science and Scopus are not redistributed (terms of use); records are identified by `rid` and DOI.

## Reproduce

```
pip install -r requirements.txt
python3 -I run_all.py
```

The analysis uses fixed seeds (bootstrap seed 20261126, 2000 replicates). Python 3.10.12, NumPy 2.2.6, pandas 2.3.3,
Matplotlib 3.10.9. Integrity: `MD5SUMS.txt`.

## Use of generative AI

The scripts were written with the assistance of generative AI under the author's direction; the author reviewed the
outputs and is responsible for the content. The article states the tool and the tasks.
